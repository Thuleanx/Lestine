# Grand Design - Project L

is a rogue-like action role playing game similar to the likes of Diablo and Path of Exile.
It is top-down 3D however changes in elevation should not affect gameplay, so all colliders can,
and should, be 2D.
Aesthetic wise, it should be toon shaded or pixel art. Avoid over realistic styles.

# Path of Exile
is a Diablo-like known for its deep character customization, itemization, and variety in content.

# Risk of Rain
is known for its roguelike loops and item stacking. In L, we want to copy some of the elements of 
this game while keeping the project an ARPG.


# Itemization

Project L will feature the following category of items:
1. Consumables: 
+ Instanced
+ Store in inventory
+ Can be consumed to grant resources or temporary bonuses
+ Stackable
2. Equipment:
+ Possibly unique / randomly generated
+ Stored in inventory
+ Can be equiped
+ Grants buff and bonuses on equip
+ Possibly grant tags on equip
3. Trinkets
+ Instanced, not unique
+ Grants buff, possibly tags on equip
+ Stored in separate inventory
4. Currencies
+ Instanced
+ Stored in inventory
+ Can be applied to an item
5. Components
+ Instanced
+ Stored in inventory
+ For crafting, and quests
